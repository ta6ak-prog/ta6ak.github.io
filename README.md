# Dodge SRT — сайт

Статичный одностраничный сайт про автомобили Dodge SRT. Готов к публикации на GitHub Pages.

## Содержимое

```
dodge-srt-site/
├─ index.html        ← главная страница
├─ .nojekyll         ← служебный файл (не удалять)
├─ README.md         ← эта инструкция
└─ images/           ← картинки (уже встроены, интернет не нужен)
   ├─ hero.jpeg
   ├─ engine.jpeg
   └─ action.jpeg
```

Все картинки лежат локально в папке `images/`, поэтому сайт работает автономно — ничего не «отвалится» со временем.

## Способ 1 — без командной строки (через сайт GitHub)

Самый простой вариант, если ты не дружишь с git.

1. Зайди на https://github.com и войди в аккаунт (или зарегистрируйся — бесплатно).
2. Нажми **New** (зелёная кнопка) → создай новый репозиторий.
   - Имя, например: `dodge-srt`
   - Поставь **Public**
   - Нажми **Create repository**
3. На странице репозитория нажми **Add file → Upload files**.
4. Перетащи туда **всё содержимое этой папки**: файл `index.html`, файл `.nojekyll` и папку `images` целиком.
   > Важно: `index.html` должен лежать в корне репозитория, а не внутри подпапки.
5. Нажми **Commit changes**.
6. Открой **Settings** (верхнее меню репозитория) → слева **Pages**.
7. В разделе **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` и папка `/ (root)` → **Save**
8. Подожди 1–2 минуты. Обнови страницу — вверху появится ссылка вида:
   ```
   https://ТВОЙ_ЛОГИН.github.io/dodge-srt/
   ```

Готово! Это и есть публичный https-адрес твоего сайта.

## Способ 2 — через git (для тех, кто умеет)

```bash
cd dodge-srt-site
git init
git add .
git commit -m "Dodge SRT site"
git branch -M main
# создай пустой репозиторий на GitHub и подставь его адрес:
git remote add origin https://github.com/ТВОЙ_ЛОГИН/dodge-srt.git
git push -u origin main
```

Затем в **Settings → Pages** выбери ветку `main` / `/ (root)` и сохрани.

---

## Проверка перед публикацией

Открой `index.html` локально двойным кликом — сайт должен открыться с картинками. Если картинки видны локально — они будут видны и на GitHub Pages.

## Дальше: подключение к Telegram-боту

Когда у тебя появится https-ссылка (`https://ТВОЙ_ЛОГИН.github.io/dodge-srt/`), её можно использовать как Mini App:

1. Открой @BotFather → `/newapp` → выбери бота.
2. В поле Web App URL вставь свою ссылку GitHub Pages.
3. Через `/setmenubutton` можно привязать кнопку меню к этому адресу.
